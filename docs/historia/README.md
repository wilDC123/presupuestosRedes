# Historia

Documentos de **cómo y por qué** se llegó a las reglas actuales. No son la referencia vigente: para eso están
`CLAUDE.md` y `docs/reglas/`.

| Archivo | Qué cuenta |
|---|---|
| `claude-md-hasta-2026-11-12.md` | El `CLAUDE.md` completo tal como estaba el 2026-11-12: cada regla con sus fechas, migraciones y lo que había antes |
| `cambios-presupuesto-vivo.md` | El paso del presupuesto con líneas sueltas al "documento vivo" (resumen para el tutor) |
| `cambios-especificaciones.md` | La librería de especificaciones (ficha, versión, emisión) y los formularios ET |
| `plan-especificaciones.md` | El plan por pasos de la librería de especificaciones |
| `cambios-codificacion-lineamiento.md` | La codificación según el lineamiento RD-GD-LI-001 |
| `cambios-unidad-area-intervencion.md` | Unidad solicitante y área de intervención (UsfxGEO) |
| `cambios-revision-2026-11-05.md` | La revisión del Ing. de DTIC del 2026-11-05 (número de proyecto, fases, ficha técnica, lista de materiales) |

Para la historia de cada archivo de código: `git log` y los PR en GitHub.
